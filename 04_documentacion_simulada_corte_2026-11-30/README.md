# Expediente de seguimiento — corte 30/11/2026

> **ADVERTENCIA DE INTEGRIDAD DOCUMENTAL:** Este expediente contiene modelos, escenarios y avances simulados con finalidad de planeación y demostración. No constituye prueba de ejecución real, no acredita asistencia, participantes inscritos, alianzas, vacantes, contrataciones ni aprobaciones. Toda cifra marcada como hipotética debe validarse con soportes auténticos antes de reportarse como resultado institucional.

## 1. Parámetros de referencia
- Proyecto: Programa Integral para la Empleabilidad y la Inclusión Productiva.
- Territorio: San Gabriel.
- Población objetivo: 200 jóvenes de 18 a 28 años.
- Duración: 12 meses.
- Inicio de referencia: septiembre de 2026.
- Cierre proyectado: agosto de 2027.
- Corte solicitado para este ejercicio: 30 de noviembre de 2026.
- Presupuesto de referencia: COP $500.000.000.
- Meta de resultado: al menos 60% de participantes (120 de 200) mejora sus condiciones de acceso al mercado laboral formal.

## 2. Criterio de corte
El corte del 30/11/2026 corresponde a un escenario de seguimiento solicitado. Las actividades posteriores a esa fecha se documentan como preparación, diseño o programación; no se declaran ejecutadas. El avance de 75% es una rúbrica simulada de completitud documental y no un porcentaje comprobado de ejecución física o financiera.

## 4. Rúbrica ilustrativa de 75%
Para cada ficha se utiliza una escala de cuatro dimensiones de igual peso (25 puntos cada una): (1) alcance y objetivo definidos; (2) metodología y responsables descritos; (3) productos/indicadores especificados; (4) evidencia verificable y validación. Un resultado ilustrativo de 75/100 significa que tres dimensiones están documentadas y la cuarta permanece pendiente de validación. No significa que la actividad se haya ejecutado al 75%.

## 6. Reglas de validación
1. No cargar datos personales identificables de jóvenes en un repositorio público.
2. Para asistencia, usar listas auténticas y autorizadas; publicar solo versiones anonimizadas.
3. Para alianzas, conservar cartas o convenios firmados y verificar autorización de publicación.
4. Para vacantes y remisiones, registrar fuente, fecha, vigencia y resultado, protegiendo datos personales.
5. No marcar una actividad como cerrada sin cumplir su criterio de cierre y adjuntar evidencia auténtica.
6. Toda simulación debe conservar la etiqueta **SIMULACIÓN — NO ES EVIDENCIA REAL**.
